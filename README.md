# Simple OpenCV Grayscale Video Converter

This is a very small Python project that converts a video to grayscale using OpenCV.

## Run it

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Convert a video:
   ```bash
   python grayscale_video.py input.mp4 output.mp4
   ```

If you do not provide an output name, the script will save to `output_grayscale.mp4`.
